# IPTV Oficial — Servidor Oficial de Streaming 4K no Brasil

Website oficial da plataforma **IPTV Oficial** (`iptvoficial.online`), a fonte oficial de transmissões em alta definição com servidores dedicados no Brasil, grade com mais de 35.000 canais ao vivo e estabilidade comprovada.

## 🚀 Tecnologias

- **Framework**: TanStack Start + Vite + React 19
- **Estilização**: Tailwind CSS v4 + Radix UI + Lucide React
- **SEO & Otimização**: Schema.org estruturado (Product, FAQPage, HowTo, BlogPosting, OfferCatalog), OpenGraph completo, Canonical Tags dinâmicas, Sitemap XML e RSS Feed nativo.
- **Identidade Visual**: Backdrop cinematográfico *Oppenheimer* otimizado em WebP leve (~80 KB), paleta Deep Quantum Charcoal & Emerald com botões Solar Gold de alto contraste e legibilidade impecável.

## 💻 Executando localmente

```sh
git clone https://github.com/kegino/iptv-oficial.git
cd iptv-oficial
pnpm install
pnpm dev
```

## 📦 Build para Produção

```sh
pnpm build
```
